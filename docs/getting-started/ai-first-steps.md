# AI と一緒に初めてのワールドを作る

AI コーディングエージェントに言葉で頼みながら、ワールドを作って公開するまでの手引きです。コードを自分で書いたことがなくても進められます。準備のコマンドも、エージェントに頼んで実行してもらいます。

## 用意するもの

- [Node.js](https://nodejs.org/) 18.0.0 以上
- [Git](https://git-scm.com/)（作業を戻せるようにするため）
- AI コーディングエージェント（次の節で選びます）
- [XRift](https://xrift.net) のアカウント（公開するときに使います）

## エージェントを選ぶ

| エージェント | 費用 | 向いている人 |
|------|------|------|
| [OpenCode Desktop](https://opencode.ai/download) | 無料で始められる | まず試したい人（おすすめ） |
| [Claude Code](https://claude.com/claude-code) / [Codex](https://openai.com/codex/) | 有料プラン | すでに契約している人、より難しいことを頼みたい人 |

**OpenCode Desktop** は macOS・Windows・Linux で動くアプリで、アカウントを作らずに使える無料のモデルが付いています。このページは OpenCode Desktop を例に進めますが、Claude Code や Codex でも、貼るプロンプトと流れは同じです。

:::note 無料のモデルについて
無料のモデルは、入力した内容がモデルの改善に使われることがあります。また、提供されるモデルは入れ替わります。詳しくは [OpenCode のドキュメント](https://opencode.ai/docs/zen/)を確認してください。
:::

## Step 1: フォルダを作ってエージェントで開く

1. [OpenCode Desktop](https://opencode.ai/download) をダウンロードして入れる
2. ワールド用の空のフォルダを作る（例: `my-world`）
3. OpenCode Desktop でそのフォルダを開く

## Step 2: 準備をエージェントに頼む

次のプロンプトをそのまま貼ります。XRift CLI の導入、プロジェクトの作成、XRift の知識（[xrift-skills](/guides/ai-agents)）の導入までをエージェントが行います。

```text
XRift のワールドを作る準備をしてください。次を順に実行し、失敗したら原因を調べて直してください。

1. `npm install -g @xrift/cli` で XRift CLI を入れる
2. `xrift create world my-world --here -y` で、このフォルダにワールドのプロジェクトを作る
3. `npx skills add WebXR-JP/xrift-skills -y` で XRift のスキルを入れる
4. `git init` して、ここまでをコミットする
5. `npm run dev` で開発サーバーを起動し、ブラウザで開く URL を教える

終わったら、入れた xrift-world スキルと AGENTS.md を読み、ワールドを作るときに守るルールを 3 行でまとめてください。以後の作業では必ずそのルールに従ってください。
```

コマンドを実行してよいか聞かれたら、内容を見て許可します。

:::tip すでにプロジェクトがある場合
スキルだけを入れるときは、次のプロンプトを貼ります。

```text
`npx skills add WebXR-JP/xrift-skills -y` を実行して XRift のスキルを入れてください。入れ終わったら xrift-world スキルを読み、以後の作業ではその内容に従ってください。
```
:::

## Step 3: ワールドを表示する

エージェントが教えてくれた URL（通常は `http://localhost:5173`）をブラウザで開くと、サンプルワールドが表示されます。

| 操作 | キー |
|------|------|
| 視点 | 画面をクリックしてからマウスを動かす |
| 移動 | W / A / S / D |
| ジャンプ | Space |
| インタラクト | 照準を合わせてクリック |
| マウスを戻す | ESC |

ファイルが変わると、ブラウザの表示も自動で更新されます。

## Step 4: 作りたいものを頼む

まずは小さなことを頼んでみます。

```text
スポーン地点の正面 3m に、赤い立方体を置いて
```

ブラウザに戻って、立方体が出ていれば成功です。続けて、次のように頼んでいきます。

```text
その立方体をクリックするたびに色が変わるようにして。色は全員に同じように見えるようにして
```

```text
public/tree.glb を読み込んで、床の四隅に置いて
```

3D モデルや画像を使うときは、ファイルを `public/` フォルダに置いてから、ファイル名を伝えます。

## 頼み方のコツ

- **1 回に 1 つだけ頼む** — 「広場を作って、椅子を置いて、音楽を流して」とまとめず、1 つずつ頼んで、そのたびにブラウザで確かめます
- **見たままを伝える** — 「椅子が床に埋まっている」「もう少し右に」「2 倍の大きさに」のように、画面で見えていることをそのまま言えば伝わります
- **エラーはそのまま貼る** — 画面が真っ白になったり赤い文字が出たりしたら、出ている文をコピーして貼り、「直して」と頼みます
- **うまくいったら記録する** — 気に入った状態になったら「ここまでをコミットして」と頼みます。あとで壊れても「最後のコミットに戻して」で戻れます
- **どの端末で遊ぶかを伝える** — XRift のワールドは PC・スマートフォン・VR から開かれます。「スマートフォンでも操作できるようにして」と添えると安心です（[対応端末](/guides/multi-device)）

## Step 5: 公開する

公開もエージェントに頼めます。

```text
このワールドを XRift に公開したいです。`xrift login` でログインしてから `xrift upload world` を実行してください。入力が必要なところは、私に聞いてください。
```

ログインではブラウザが開くので、XRift のアカウントでログインします。初回はタイトルや説明を聞かれます。アップロード後にコードの審査が自動で行われ（通常数分）、通過するとワールドが公開されます。審査に落ちたときは、表示された内容をエージェントに貼って直してもらいます。

## うまくいかないとき

| 症状 | 試すこと |
|------|----------|
| 頼んだものが画面に出ない | 「画面に出ていない」と伝える。位置が遠い・床の下にあることが多いです |
| 画面が真っ白になった | ブラウザに出ているエラーを貼って直してもらう |
| 直らずに行ったり来たりする | 「最後のコミットに戻して」で戻し、頼み方を小さく分ける。モデルを別のものに変えるのも手です |
| XRift にない書き方をしている | 「`npx skills update` でスキルを最新にして、読み直して」と頼む |
