# AI エージェントでワールドを編集する

ブラウザの AI エージェントに「ここに椅子を10脚並べて」と頼むと、XRift のワールドに
オブジェクトが置かれます。ブラウザで編集できるワールド（EDITOR 型）が対象で、
[WebMCP](https://developer.chrome.com/docs/ai/webmcp) という仕組みを使っています。

エージェントが置いたものは、その場にいる全員の画面にすぐ反映され、ワールドに保存されます。
手で置いたときとまったく同じ扱いなので、`Cmd/Ctrl+Z` で取り消せますし、インスペクタから
続きを編集できます。

## WebMCP とは

ページが「この操作ができます」という一覧をブラウザに登録しておくと、ブラウザに組み込まれた
AI エージェントがそれを呼べる、という仕組みです。エージェントは画面をクリックする代わりに
ページが公開した関数を直接呼ぶので、UI の見た目に左右されずに操作できます。

XRift はワールド編集の操作をこの形で公開しています。エージェント側が WebMCP に対応して
いれば、拡張機能を入れたりしなくてもツールが見えます。

## 必要なもの

| | |
|---|---|
| ブラウザ | Chrome 149 以降 |
| サイト | `https://app.xrift.net` |
| ワールド | ブラウザで編集できるワールド（EDITOR 型） |
| 権限 | そのワールドのオーナー、または編集を許可されたユーザー |

インスタンスに入って、画面に編集ボタン（🔧）が出ていれば準備完了です。**編集モードに
入る必要はありません**。歩きながら「そこに壁を立てて」と頼めます。

:::note

Chrome の Origin Trial（試験公開）で提供しているため、**2026年11月17日まで**は
`app.xrift.net` でそのまま使えます。それ以降は仕様の正式化の状況によって、
再度の対応が必要になる場合があります。

:::

## できること

エージェントには次の操作が見えています。ユーザーが直接名前を呼ぶ必要はなく、
やりたいことを日本語で伝えれば、エージェントが適切なものを選びます。

| 操作 | 内容 |
|---|---|
| `list-placeable-types` | 置ける種別と、その寸法の範囲を調べる |
| `get-scene` | 今ワールドに何が置かれているかを調べる |
| `get-viewer-context` | ユーザーがどこを見ているか、あと何個置けるかを調べる |
| `place-objects` | まとめて配置する（1回に最大50個） |
| `update-objects` | 位置・回転・大きさ・寸法・色・素材を変える |
| `remove-objects` | 消す（グループは中身ごと） |
| `group-objects` | 複数をひとつのグループにまとめる |
| `undo-last-agent-edit` | AI が直前にやったことを取り消す |

置ける種別は **箱・床・壁・球・円柱** の5つです。画像パネルや画面共有スクリーンは、
URL や配信元を AI に創作させたくないので対象外にしています。リスポーン地点も、
全員の入室位置が変わってしまうので人が置きます。

## 頼み方のコツ

**基準を言葉で伝える。** 「ワールドの原点に」なら絶対座標で、「私が今見ているところに」
なら見ている面を基準に置いてくれます。後者のほうが位置の指示が楽です。

```
目の前の床に、2m 四方のステージを作って
```

**寸法はメートルで。** XRift の座標系は1単位＝1メートルです。「3m の壁」「半径50cm の球」
のように実寸で伝えると、そのまま通ります。

**まとめて頼む。** 「椅子を5脚、2m 間隔で並べて」のように数と間隔を言えば、1回の呼び出しで
まとめて置かれます。1個ずつ頼むより速く、取り消しも1回で済みます。

**作り終えたらグループ化を頼む。** 「今作ったベンチをグループにまとめて」と言えば、
以降は1つの物として動かしたり消したりできます。

**気に入らなければすぐ戻す。** 「今のを取り消して」で戻せます。`Cmd/Ctrl+Z` でも同じです。

## 動いていることの確認

エージェントが何かを置くと、画面上部にバナーが出ます。

- **選択** — 置かれたものを選びます（編集モードに入ります）。位置を微調整したいときに使います
- **元に戻す** — 取り消します（`Cmd/Ctrl+Z` と同じ）
- **✕** — バナーを閉じます

バナーは10秒で自動的に消えますが、消えても取り消しはできます。

## ユーザーの操作が優先されます

AI はユーザーの操作を横取りしません。

- **選択を奪わない** — インスペクタで何かを編集している最中に AI が物を置いても、
  選択は変わりません
- **モードを勝手に切り替えない** — 編集モードのオン・オフは変わりません
- **操作中は断る** — 自分で物を置いている途中や移動（M）の途中は、AI の変更要求は
  拒否されます。削除の確認ダイアログに答えている最中も同じです
- **他の人が編集中のものは触らない** — 誰かが選択中のオブジェクトは変更・削除の対象から
  外れ、「他の人が編集中の N 個は残っています」と報告されます

## うまくいかないとき

**エージェントにツールが見えない**

1. `https://app.xrift.net` を Chrome 149 以降で開いているか
2. インスタンスに入っているか（一覧画面では登録されません）
3. 編集ボタン（🔧）が出ているか。出ていなければ、そのワールドの編集権限がないか、
   ブラウザで編集できないワールド（コードで作られた CODE 型）です

**「オブジェクト数が上限に達しています」**

1つのワールドに保存できるオブジェクトは500個までです。`get-viewer-context` で
残り枠を確認できます。要らないものを消してから頼み直してください。

**思ったのと逆側に置かれる**

「私の前」の基準が伝わっていない可能性があります。「私が今見ている壁に」のように、
見ているものを具体的に言うと安定します。

**置いたはずのものが見つからない**

バナーの「選択」を押すと、置かれたものが選択された状態で編集モードに入ります。
地面の下や遠くに置かれてしまった場合もこれで見つけられます。

## 開発者向け

ツールの入出力スキーマ、座標や回転の規約、エージェント側の実装で踏みやすい落とし穴は
[xrift-skills](https://github.com/WebXR-JP/xrift-skills) の `xrift-world-editing`
スキルにまとめてあります。AI コーディングエージェントに読み込ませる形式です。

```bash
npx skills add WebXR-JP/xrift-skills
```
