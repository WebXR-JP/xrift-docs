# Public API v1

API reference for external developers to access XRift data using API keys.

**Base URL**: `https://api.xrift.net/api/public/v1`

## Authentication

Two authentication methods are supported. Send the token via the `Authorization` header.

| Method | Header | Use case |
|---|---|---|
| API Key | `Authorization: Bearer xrift_sk_xxx` | For third-party developers (scoped + rate limited) |
| CLI Token | `Authorization: Bearer xrf_xxx` | For CLI / internal tools (full access, no rate limit) |

You can obtain an API key from the [XRift settings page](https://app.xrift.net/settings).

- API keys are identified by the `xrift_sk_` prefix
- CLI tokens are identified by the `xrf_` prefix
- Tokens that don't match either format will return a `401` error

### Scopes

API key authentication uses scope-based access control. If the required scope is missing, a `403` error is returned.

| Scope | Access |
|---|---|
| `read:worlds` | World list, search, details, popular ranking, stats, and user's public worlds |
| `read:users` | User public profile and user search |
| `read:instances` | Instance list, details, and world instances |
| `read:marketplace` | Marketplace listings: list, search, and details |
| `read:events` | Event list and details |
| `read:friends` | Your online friends (including where they are) |

:::tip
CLI tokens skip scope checks and have access to all endpoints.
:::

## Endpoints

### GET /worlds

List worlds with pagination.

- **Scope**: `read:worlds`

#### Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | number | 20 | Number of items (max 50) |
| `offset` | number | 0 | Offset |

#### Request example

```bash
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/worlds?limit=10&offset=0"
```

#### Response example

```json
{
  "data": [
    {
      "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "name": "My World",
      "description": "A sample world",
      "ownerId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "isPublic": true,
      "createdAt": "2026-01-01T00:00:00.000Z",
      "updatedAt": "2026-01-01T00:00:00.000Z"
    }
  ],
  "pagination": {
    "total": 100,
    "limit": 10,
    "offset": 0
  }
}
```

### GET /marketplace/items

Get the list of items listed on the marketplace. Only public items that have passed review are returned.

- **Scope**: `read:marketplace`

#### Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `sort` | string | - | `popular` | Sort order (`popular`: most acquired / `newest`: newest first / `trending`: recent momentum) |
| `ownerId` | string | - | - | Only return listings by this user |
| `limit` | number | - | 20 | Number of results (1–50; values above 50 are treated as 50) |
| `offset` | number | - | 0 | Offset (0 or greater) |

:::note
With `sort=trending`, items that haven't been acquired recently are not included.
:::

#### Request example

```bash
# Most popular
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/marketplace/items?limit=10"

# A specific user's listings, newest first
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/marketplace/items?ownerId=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx&sort=newest"
```

#### Response example

```json
{
  "data": [
    {
      "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "name": "Picture Frame",
      "description": "A frame for displaying photos",
      "sceneUrl": "https://assets.xrift.net/.../remoteEntry.js",
      "thumbnailUrl": "https://assets.xrift.net/.../thumbnail.png",
      "githubUrl": null,
      "fileSize": "1048576",
      "status": "ACTIVE",
      "securityScore": 0,
      "isPublic": true,
      "currentVersionNumber": 2,
      "acquireCount": 42,
      "permissions": {
        "allowedDomains": [],
        "allowedCodeRules": []
      },
      "owner": {
        "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "displayName": "sawa-zen",
        "userIconUrl": "https://example.com/avatar.png"
      },
      "createdAt": "2026-01-01T00:00:00.000Z",
      "updatedAt": "2026-01-01T00:00:00.000Z"
    }
  ],
  "pagination": {
    "total": 99,
    "limit": 10,
    "offset": 0
  }
}
```

- `fileSize` is the size in bytes, returned as a string

#### Errors

The validation error messages for this endpoint are returned in Japanese.

| Status | Condition | Response |
|---|---|---|
| 400 | Invalid `sort` | `{ "error": "sort は popular、newest、trending のいずれかを指定してください" }` |
| 400 | Empty `ownerId` | `{ "error": "ownerId は空にできません" }` |
| 400 | `limit` / `offset` is not a decimal integer (`1.5`, `1e2`, `0x10`, etc.), or `limit` is 0 | `{ "error": "limit は 1 以上の整数を指定してください" }` |

:::note
Passing the ID of a user who doesn't exist as `ownerId` is not an error; an empty list is returned.
:::

### GET /events

Get the list of events. Recurring events are expanded into each occurrence within the requested period.

- **Scope**: `read:events`

#### Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `from` | string | **Required** | - | Start of the period (ISO 8601) |
| `to` | string | **Required** | - | End of the period (ISO 8601). Within 366 days of `from` |
| `worldId` | string | - | - | Filter by venue world |
| `instanceId` | string | - | - | Filter by instance |
| `ownerId` | string | - | - | Filter by organizer |
| `kind` | string | - | - | `scheduled` / `instant` |
| `status` | string | - | - | `upcoming` / `live` / `ended` / `cancelled` |
| `order` | string | - | `asc` | Sort order by start time (`asc` / `desc`) |
| `limit` | number | - | 20 | Number of results (1–50; values above 50 are treated as 50) |
| `offset` | number | - | 0 | Offset (0 or greater) |

#### Request example

```bash
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/events?from=2026-12-01T00:00:00Z&to=2026-12-31T23:59:59Z&limit=10"
```

#### Response example

```json
{
  "data": [
    {
      "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx::2026-12-02T13:00:00.000Z",
      "seriesId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "kind": "scheduled",
      "status": "upcoming",
      "title": "VR Catch-up",
      "description": "A catch-up meetup every two weeks",
      "thumbnailUrl": null,
      "worldId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "currentUsers": 0,
      "instanceId": null,
      "startAt": "2026-12-02T13:00:00.000Z",
      "endAt": "2026-12-02T14:00:00.000Z",
      "repeatFrequency": "biweekly",
      "owner": {
        "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "displayName": "sawa-zen",
        "userIconUrl": "https://example.com/avatar.png"
      },
      "createdAt": "2026-10-01T00:00:00.000Z",
      "updatedAt": "2026-10-01T00:00:00.000Z"
    }
  ],
  "pagination": {
    "total": 139,
    "limit": 10,
    "offset": 0
  }
}
```

- Each occurrence of a recurring event has an `id` of the form `{series ID}::{original start time of the occurrence}`, and `seriesId` holds the series ID. One-off events use their plain ID and have no `seriesId`
- `world` contains the venue world (omitted when the world has no published version)
- `instance` is only present for instant events (`kind: instant`) and contains the running instance
- `status` is the actual state based on the time of the request

#### Errors

The validation error messages for this endpoint are returned in Japanese.

| Status | Condition | Example response |
|---|---|---|
| 400 | `from` / `to` is missing | `{ "error": "from と to（表示範囲）は必須です（ISO 8601）" }` |
| 400 | `from` / `to` is not a valid date | `{ "error": "from は有効な日時（ISO 8601）を指定してください" }` |
| 400 | `from` is after `to` | `{ "error": "from は to 以前を指定してください" }` |
| 400 | The period exceeds 366 days | `{ "error": "取得期間（from〜to）は366日以内で指定してください" }` |
| 400 | Invalid `kind` / `status` / `order`, or empty `ownerId` | An error for that parameter |
| 400 | `limit` / `offset` is not a decimal integer, or `limit` is 0 | `{ "error": "limit は 1 以上の整数を指定してください" }` |

### GET /events/:id

Get the details of the event with the specified ID.

- **Scope**: `read:events`

#### Path parameters

| Parameter | Type | Description |
|---|---|---|
| `id` | string | Event ID. Occurrence IDs of recurring events (`{series ID}::{time}`) are also accepted |

With an occurrence ID, the details of that occurrence are returned (its own time, plus any changes made to that occurrence only). With a series ID, the series is returned (with the time of the first occurrence).

:::tip
Occurrence IDs contain `:`, so URL-encode them before use.
:::

#### Request example

```bash
# One-off event or series
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/events/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

# An occurrence (xxxxxxxx-...::2026-12-02T13:00:00.000Z, URL-encoded)
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/events/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx%3A%3A2026-12-02T13%3A00%3A00.000Z"
```

#### Response example

Returns the same shape as each element of `GET /events`, under `data`.

```json
{
  "data": {
    "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx::2026-12-02T13:00:00.000Z",
    "seriesId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "title": "VR Catch-up",
    "startAt": "2026-12-02T13:00:00.000Z",
    "endAt": "2026-12-02T14:00:00.000Z",
    "repeatFrequency": "biweekly"
  }
}
```

(Some fields are omitted.)

#### Errors

| Status | Condition | Response |
|---|---|---|
| 404 | Event doesn't exist, the occurrence was cancelled, or the time isn't part of the series | `{ "error": "Event not found" }` |

### GET /friends/online

Returns the API key owner's friends who are online right now.

- **Scope**: `read:friends`

Only online friends are returned (offline friends, pending friend requests, and banned users are not included). There is no pagination.

Where a friend is (instance and world) follows the same rules as the friend list in the XRift app.

| Friend's state | What is returned |
|---|---|
| In a public instance of a public world | Included with location (`instanceId` etc.) |
| In a private instance, or in a private world | Included with location set to `null` only if the friend has turned on "show me as online in private". Otherwise not included |
| Online but not in any instance | Included with location set to `null` |

#### Request example

```bash
curl -H "Authorization: Bearer xrift_sk_xxx" \
  "https://api.xrift.net/api/public/v1/friends/online"
```

#### Response example

```json
{
  "data": [
    {
      "user": {
        "id": "user-uuid-1",
        "displayName": "Alice",
        "userIconUrl": "https://example.com/avatar.png"
      },
      "instanceId": "instance-uuid",
      "instanceName": "Main Lobby",
      "worldId": "world-uuid",
      "worldName": "My World",
      "connectedAt": "2026-11-22T10:00:00.000Z"
    },
    {
      "user": {
        "id": "user-uuid-2",
        "displayName": "Bob",
        "userIconUrl": null
      },
      "instanceId": null,
      "instanceName": null,
      "worldId": null,
      "worldName": null,
      "connectedAt": "2026-11-22T09:30:00.000Z"
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `user` | object | The friend's `id` / `displayName` / `userIconUrl` |
| `instanceId` | string \| null | ID of the instance they are in. `null` when the location is not shown |
| `instanceName` | string \| null | Instance name |
| `worldId` | string \| null | World ID |
| `worldName` | string \| null | World name |
| `connectedAt` | string \| null | When they connected (ISO 8601) |

If no friends are online, `data` is an empty array.

## Rate limiting

- **1,000 requests** per hour (default)
- Applies to API key authentication only (CLI tokens are exempt)
- Calculated using a fixed window algorithm

Rate limit usage is returned via response headers (API key authentication only).

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Maximum requests allowed |
| `X-RateLimit-Remaining` | Remaining requests |
| `X-RateLimit-Reset` | Reset time (Unix timestamp) |

:::caution
When the rate limit is exceeded, a `429 Too Many Requests` response is returned. Wait until the time indicated in the `X-RateLimit-Reset` header before retrying.
:::
